Development Progress Report

Crafton 网站与制造管理平台开发进度汇报

从品牌主页升级到覆盖 S01–S17 的订单运营工作台，项目已完成主要界面搭建，正式进入系统测试与流程验证阶段。

Testing in progress 汇报日期：2026 年 7 月 16 日
01 / OVERVIEW

本阶段完成三项关键推进

网站展示层与内部运营层同步演进。对外页面更聚焦家具产品与定制服务，对内管理控制台已经覆盖 17 阶段制造流程的主要业务界面。

01

新增 Set Furniture

主页增加成套家具入口，以产品类别组织成熟家具款式，帮助客户更直接地浏览、选择并发起定制。

02

调整主页品牌表达

删除主页上有关 AI 的表述，将前台沟通重点回归高端定制家具、材料、工艺、合规与交付能力。

03

管理后台进入测试

管理员控制台主体已经基本搭建完成，现阶段重点转入数据联调、权限验证、异常流程和真实项目测试。

02 / WEBSITE

主页内容更聚焦产品与客户决策

新增产品分类展示后，客户可以从成熟家具形态出发，再进一步定制尺寸、材质、颜色及区域合规要求。主页的沟通语言也完成调整，减少技术概念对客户决策的干扰。

Set Furniture 产品入口

首批页面展示六个核心家具类别，为后续产品详情、配置选项与询价流程建立统一入口。

  • 01沙发与休闲座椅
  • 02边桌与餐桌
  • 03餐椅与媒体柜
  • 04支持尺寸、材料与颜色定制

合规要求前置

订单提交表单已加入英国、美国、欧盟及澳新市场的家具防火与安全标准选项。客户需求从入口处结构化记录，为后续规格审核、询价和验收提供一致依据。

03 / OPERATIONS

管理员控制台已覆盖 17 阶段制造流程

后台界面已经形成从客户订单接收到最终归档的完整工作区结构。各业务阶段已具备状态、数据区、审核动作与操作入口，目前正通过测试项目验证前后阶段的数据衔接。

S01–S05

订单接收与审核

客户资料、缺失项检查、BOM 与双语规格草稿、最终审批。

S06–S08

询价与供应商决策

RFQ 生成与发送、报价标准化对比、最优供应商审批。

S09–S11

生产与质量控制

生产计划、延期风险、进度证据、视觉质检与放行。

S12–S17

出货与交付归档

装柜、单证、物流追踪、拆分交付、客户交接与审计归档。

当前状态：基础搭建完成，进入测试阶段

页面结构和主要业务入口已经具备；现阶段将重点验证真实数据、角色权限、跨阶段状态流转、异常处理与操作记录。

IN TESTING
04 / NEXT

下一阶段工作重点

  1. 完成端到端流程测试使用真实测试订单验证上传、审核、询价、生产、质检到出货归档的数据闭环。
  2. 完善权限与审批机制验证客户、管理员和供应商的角色边界，以及关键节点的人工确认与操作留痕。
  3. 优化异常状态与提示补全资料缺失、报价异常、延期、质检不通过和单证缺失等业务分支。
  4. 根据测试反馈优化体验调整后台信息密度、操作顺序、移动端表现，并准备下一轮内部验收。
